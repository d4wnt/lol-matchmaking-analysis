# League of Legend Matchmaking Analysis

## Objective

This project analyzes League of Legends matchmaking using Riot's official API.

## Features

- Riot API integration
- Match data collection
- SQLite/PostgreSQL storage
- Statistical analysis
- Data visualization

## Planned APIs

- Match-V5
- Account-V1
- League-V4

## Research Questions

- Does recent win streak affect teammate quality?
- Does queue time affect matchmaking?
- Are teammate recent win/loss records statistically different after consecutive wins?
